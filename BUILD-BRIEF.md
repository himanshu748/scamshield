# Real-input product increment

Approved direction: a local-first message-checking workspace. People paste their own SMS, email or chat text, inspect redacted evidence, and choose whether to generate a downloadable report. Reopen or delete saved cases. Keep examples optional and the current visual identity intact.

Preserve redaction before storage and model input, never open suspicious links, and distinguish local deterministic checks from live AI. No automatic forwarding, cloud deployment, or AWS spend in this increment. This remains individual case review, not a shared community reporting network. Proof: custom-input analysis, persisted reopening, deletion, report download, failure recovery. First risk: private data retention.
